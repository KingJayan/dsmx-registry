# Toolkit

The steps you run at the end of every session, behind one key.

## Routines

Pick one in the panel, then press `Alt+Enter`.

| routine | what it runs |
| --- | --- |
| tidy | format → compile |
| ship | format → save → export png |
| share | format → save → copy share link |
| vector | format → save → export svg |

The choice is remembered, and follows you to another machine.

## Panels on Alt

| key | opens |
| --- | --- |
| `Alt+1` | format the file |
| `Alt+2` | the optimizer report |
| `Alt+3` | problems |
| `Alt+4` | the expression view |

The same four are rows in the panel, for when you would rather click.

## Elsewhere

Right-click the editor or the graph for **Run the toolkit routine**, and the editor for
**Count the statements**. The status bar shows the routine you are on; click it to run.

## What it can reach

Toolkit only asks the app to do things you can already do yourself — format, compile,
save, export, switch view, open a panel. It reads the editor to count lines. It writes
nothing on its own.
