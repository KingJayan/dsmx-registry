# Midnight Grid

A dark blue theme for the editor. Deeper than the built-in dark, with less contrast
between the lines and more between the things you are actually reading: keywords in
blue, numbers in amber, strings in green and comments well out of the way.

## Using it

Install it, then pick **Midnight Grid** in settings under the editor theme.

## What it touches

The editor only. Desmos draws the graph itself, so the grid, the axes and the curves
keep their own colours — a theme cannot reach them.

This plugin ships no code and no DSL. It is a colour table and nothing else.
